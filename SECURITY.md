# Security Policy

## Supported Versions

Security updates are provided for the latest released version on `main` and the latest patch release of actively maintained release branches.

## Reporting a Vulnerability

If you discover a security issue, do not open a public issue.

Report it privately by email to opensource@amadeus.com and include:

- A clear description of the issue and impact
- Steps to reproduce or a proof of concept
- Affected versions, modules, and configuration
- Any proposed mitigation or fix

You can expect an acknowledgement within 5 business days. We will validate the report, coordinate remediation, and disclose fixes responsibly once a patch is available.

## Disclosure Process

- We validate and triage the report
- We prepare and test a fix
- We publish a coordinated security advisory and patch release

Please help protect users by keeping details private until a fix is released.
